# Repository agent instructions

- Never add co-authors to commits. Use the user's Git identity alone and a lowercase Conventional Commit subject. The user has authorized committing and pushing each completed requested change or feature; validate it, stage only intended paths, commit, and push to the current branch on origin. A later request not to commit or push overrides this standing instruction. Never force-push or discard unrelated work.
- For Chameleon implementation or evaluation, read [agent-kit/README.md](agent-kit/README.md), then [agent-kit/AGENTS.md](agent-kit/AGENTS.md). These are repository-wide working guidance by explicit reference.
- The agent kit describes future implementation work; creating or reading it does not authorize starting an agent tournament, publishing, or submitting anything.
